楽天証券 — テスト環境から最大1,125万口座の情報流出の恐れ

2026年11月18日時点：11月17日、同社はテスト環境で管理していた一部情報が外部に漏えいしたおそれがあると公表。不正アクセスの原因・経緯は調査中です。月次レポート：2026年11月 月次レポート。

概要（非エンジニア向け）：楽天証券（15百万超の口座を持つオンライン証券）は、2026年11月16日に第三者による不正アクセスの可能性を検知し、該当箇所へのアクセス遮断・修正を実施。調査の結果、11月11日にテスト環境内の一部情報が外部へ漏えいしたおそれがあることを確認し、11月17日に公表・謝罪しました。影響は最大約1,125万口座（部店・お客様コード、ログインID）、うち最大約447万口座では氏名・住所等の個人情報や金融情報も含まれます。ログインに必要なパスワード、暗証番号を含む取引に必要な情報の漏えいは確認されておらず、本件に起因する不正アクセス・不正取引も現時点で確認されていません。

1. 概要

  • 対象：楽天証券（楽天グループ全体ではない）企業公表。
  • 流出元：テスト環境のシステム。NHK は「社内システム」と表現しますが、公式発表は「テスト環境」です。
  • 原因：未公表（調査中）未確認。
  • 数値の注意：「最大1,572万口座」という見出しは二つの数値の単純合算で、公式の件数ではありません。公式発表は二つの区分を別項目で列挙しており、包含関係は明記されていません。
  • 別件（混同注意）：10月31日公表の、デジタル特典付き社債購入者362名の情報が第三者システム（NTTデータ委託先）経由で漏えいした可能性の件。同社システムへのアクセスはないとしています。

流出が確認されていない情報（公式）：ログインに必要なパスワード、暗証番号を含む取引に必要な各種情報。本件に起因する不正アクセス・不正取引は現時点で確認されていません。「確認されていない」は「流出していないと確定」とは異なります。

4. 対応・利用者向け対策

  • 同社は謝罪し、影響を受けたお客様の特定を完了、該当のお客様へ個別に報告。原因・範囲の調査とセキュリティ強化を継続。
  • 楽天証券をかたるメール・SMS・電話・郵送に注意。同社のメールには URL を記載せず、電話で個人情報やログイン情報を尋ねることはないとしています。
  • パスキー認証の利用を推奨。セキュリティ設定ページで取引・出金の一時停止が可能。問い合わせ：0120-862-274。二次情報（AliasFleet）はパスキーが必須化されると伝えていますが、公式発表では未確認です。
  • 監督当局：発表には警察や個人情報保護委員会（PPC）への言及はなく、届出状況は未公表。

5. PiraGo の推奨事項

  1. 本番データをテスト環境に持ち込まない：合成データまたは管理されたマスキング済みデータを使用し、本番 DB の丸ごとコピーを禁止。
  2. テスト/ステージングも実際の攻撃対象と考える：SSO + MFA、VPN/IP 許可リスト、ログ・監視を本番と同水準に。
  3. 定期的な棚卸しと削除：退会者を含む個人データが副次環境に残っていないか、保持ポリシーに沿って確認。
  4. 顧客通知の準備：流出した情報と未確認の情報を明確に区別し、フィッシング対策とパスキー/MFA を案内。
