PHP CVE-2026-109618, -109619 ("PHP2Shell", CVSS 9.2, chiếm server từ xa không cần đăng nhập). Ngày 10-23 công bố thêm thông báo CVE-2026-115560: nguy cơ RCE nếu đổi serialize handler sang php ở runtime trong khi bật upload progress. Nghiêm trọng Mọi ứng dụng PHP (PHP-FPM, mod_php, FrankenPHP, LiteSpeed), kể cả Laravel, Drupal. Nhánh 8.1 trở xuống đã EOL không có bản vá chính thức. Nâng PHP lên 8.5.12 / 8.4.27 / 8.3.36 / 8.2.35. Đặt thêm session.upload_progress.enabled = 0 trong php.ini để phòng ngừa CVE-2026-115560. Chi tiết
Node.js Bản phát hành 10-21: lỗi Brotli ghi ngoài vùng nhớ (có thể chiếm quyền, CVE-2026-111497); 2 lỗi bỏ qua kiểm tra tên miền của chứng chỉ TLS (CVE-2026-105483, -106069); lỗi dns.resolve (CVE-2026-105482). Thêm 6 lỗi nhẹ hơn. Cao Dịch vụ chạy Node.js 22.x, 24.x, 26.x (API, SSR, worker, Next.js, Nuxt). Client gọi HTTPS bằng Node có nguy cơ bị nghe lén. Nâng lên 26.12.1 / 24.22.1 / 22.23.4. Bản đã hết hỗ trợ (EOL) luôn bị ảnh hưởng, cần chuyển bản.
Java Oracle CPU 10-20: 55 bản vá cho Java SE, 49 lỗi khai thác từ xa không cần đăng nhập (điểm cao nhất khoảng 7.5). AWS Corretto phát hành bản vá cập nhật trust bundle cho sự cố eMudhra CA. Cao Oracle JDK/JRE, OpenJDK và Amazon Corretto cùng nhánh, gồm ứng dụng Spring Boot. Nặng hơn với ứng dụng chạy mã không tin cậy. Nâng lên 27.0.1 / 25.0.5 / 21.0.13 / 17.0.21 / 11.0.33 / 8u511 hoặc Corretto tương ứng. Đợt tiếp theo: 11-17.
.NET (gồm ASP.NET Core) Patch Tuesday 10-13: hơn 30 CVE cho .NET, 13 CVE cho ASP.NET Core. Đáng chú ý: 5 lỗi chạy mã từ xa (CVSS 8.8), CVE-2026-88092 (can thiệp request, 9.4), CVE-2026-70188 (bỏ qua bảo mật, 9.1). Microsoft xếp tất cả mức Important, chưa thấy bị khai thác. Cao Ứng dụng .NET 8/9/10 và .NET Framework (Windows, Linux, container); web/API ASP.NET Core, nhất là sau reverse proxy. Cập nhật runtime/SDK bản tháng 10, build lại image container.
JavaScript (trình duyệt + npm) Trình duyệt: Chrome 155 (10-06) sửa 247 lỗi, 4 lỗi Critical; các bản cập nhật 10-13, 10-15 và bản cập nhật desktop ngày 10-20 tiếp tục vá bổ sung. npm: chiến dịch gói độc hại giả "Apex Web3" (10-13) phát tán mã đánh cắp dữ liệu, nhắm cả AI coding agent. Cao Người dùng Chrome, Edge, Brave; ứng dụng Electron/WebView; máy dev và pipeline CI cài gói npm. Cập nhật trình duyệt và Electron. Dùng lockfile, npm ci, tắt install script khi không cần, kiểm tra gói mới thêm.

3. Framework

Thành phầnTóm tắt lỗ hổngMức độẢnh hưởng tới hệ thống nàoCách xử lý
Next.js Bản vá 10-14: (1) chiếm quyền server từ xa khi use cache trả về typed array (GHSA-673q-mjm6-r5xr), không có cách né tạm; (2) chiếm quyền qua Image Optimization với file SVG (CVE-2026-96889, GHSA-2464-fhr4-w9xw); (3) làm sập server qua Server Actions (GHSA-p3m5-59mp-jv5r). Nghiêm trọng Ứng dụng Next.js 15.x và 16.x dùng App Router. Lỗi Image Optimization đến từ thư viện sharp, chạy trên Linux glibc. Nâng lên 16.4.1 / 15.5.28. Riêng CVE-2026-96889 có thể tạm dùng sharp ≥ 0.35.5.
Laravel Advisory 10-19: CVE-2026-114509 (CVSS 9.2, GHSA-f9x3-7vq9-cph6) giả danh người dùng mà không cần token khi dùng MySQL/MariaDB. CVE-2026-114508 (6.5, GHSA-5wcm-3v2w-8362): request đọc có thể kích hoạt xóa dữ liệu bảng liên quan. Nghiêm trọng Ứng dụng Laravel dùng guard token API (TokenGuard) trên MySQL/MariaDB; ứng dụng nạp quan hệ trên endpoint chỉ đọc. Vẫn cần vá PHP phía dưới. Nâng lên bản mới nhất 13.38.0 / 12.70.1 (tối thiểu 13.29.0 / 12.68.0). Luôn tắt APP_DEBUG ở production.
Nuxt 5 advisory ngày 10-16: bỏ qua route rules/middleware khi đường dẫn khác chữ hoa/thường (GHSA-vjh5-4x84-xrqp) hoặc mã hóa % (GHSA-6gq8-jgmh-3ffp); useHeadSafe render dữ liệu chưa khử khuẩn ở Server Islands (GHSA-xfq5-w38q-pc2x); lỗi URL javascript: ở <NuxtLink> (GHSA-jjm6-p2m9-9w4x); lỗi getRouterParam với %3F (GHSA-w7gw-66vg-99gq). Còn hiệu lực: CVE-2026-71316 (lộ dữ liệu SSR cache). Cao Ứng dụng Nuxt 3/4 dùng route rules, middleware, server island, hoặc cache SSR. Lưu ý: Nuxt 3 đã kết thúc vòng đời (EOL 31-07-2026) và không được nhận bản vá cho các lỗi này. Nâng Nuxt lên ≥ 4.6.2 (hoặc bản phụ 4.4.4 / 4.5.2). Với dự án Nuxt 3, cần lên kế hoạch nâng cấp lên Nuxt 4 do nhánh 3.x không còn được hỗ trợ.
Quasar Các advisory bảo mật (prototype pollution ở extend() - GHSA-qgrf-j65m-5hh8; treo server SSR do regex User-Agent - GHSA-68jq-fhch-4xq4; rò rỉ env trang lỗi dev SSR - GHSA-r5mf-4r5x-q78f; ghi file qua icongenie - GHSA-wmpw-j6qv-mw88) đều đã được khắc phục hoàn toàn trên các bản hiện tại. Trung bình Ứng dụng Quasar dùng SSR/SSG; máy dev dùng icongenie, @quasar/cli, @quasar/app-vite. Nâng Quasar lên bản mới nhất ≥ 2.35.2 và @quasar/app-vite ≥ 3.10.3. Tắt trang lỗi SSR dev ở môi trường dùng chung.
Spring Boot Không có advisory mới trong tháng 10 (advisory gần nhất từ tháng 8). Còn hiệu lực: CVE-2026-40976 (CVSS 9.1) cấu hình bảo mật web mặc định không có tác dụng, mở mọi endpoint (4.0.0 đến 4.0.5). Tháng 9 có hơn 50 CVE từ Tomcat, Netty. Trung bình Spring Boot 4.0.0 đến 4.0.5 không tự cấu hình Spring Security; ứng dụng dùng Tomcat/Netty cũ. Dùng Spring Boot ≥ 4.0.6 / 3.5.14, cập nhật Tomcat/Netty, quét phụ thuộc kỹ.

5. Ghi chú về độ tin cậy

  • Đã đối chiếu trực tiếp nguồn chính thức: Node.js, Next.js, advisory Laravel (GitHub Advisories), advisory Nuxt (GitHub Advisories - xác nhận vá tại 4.6.2, Nuxt 3 EOL), Quasar (GitHub Advisories & Releases - xác nhận vá triệt để tại bản 2.35.2 / app-vite 3.10.3), php.net (thông báo cập nhật CVE-2026-115560 ngày 10-23), toàn bộ bản tin AWS (đến 2026-150-AWS ngày 10-24), toàn bộ bản tin Google Cloud (đến GCP-2026-072 ngày 10-24), danh sách CVE Microsoft qua SANS ISC.
  • Chỉ qua bài tổng hợp: Oracle CPU (trang trả về 403, chưa có danh sách đầy đủ từng CVE của Java SE); CVE-2026-48019 (Laravel) và CVE-2026-40976 (Spring Boot).
  • AWS: Bản tin AWS không phân loại mức độ đồng nhất (hầu hết gắn Important hoặc không ghi), cột mức độ trong bảng là đánh giá phân loại rủi ro kỹ thuật. .NET: mức độ theo CVSS và loại lỗi (Microsoft xếp tất cả Important).
  • Sự cố eMudhra CA (CVE-2026-111943): Đã được cả AWS (2026-150-AWS) và GCP (GCP-2026-071) xác nhận; chú ý hạn chót thay thế chứng chỉ trên AWS là 28-10-2026.
