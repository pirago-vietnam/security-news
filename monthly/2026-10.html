PHP CVE-2026-109618, -109619 ("PHP2Shell"). Chỉ cần gửi một request đặc biệt là chiếm được server, không cần đăng nhập (CVSS 9.2). Có báo cáo bị khai thác từ 10-17. Nghiêm trọng Mọi ứng dụng PHP, kể cả Laravel (PHP-FPM, mod_php, FrankenPHP, LiteSpeed). Nhánh 8.1 trở xuống không có bản chính thức. Cập nhật code ứng dụng không giúp được. Nâng PHP lên 8.5.12 / 8.4.27 / 8.3.36 / 8.2.35 rồi restart. Bản cũ: dùng bản backport của distro hoặc nâng nhánh. Chi tiết
Node.js Bản phát hành 10-21: lỗi Brotli ghi ngoài vùng nhớ (có thể chiếm quyền, CVE-2026-111497); 2 lỗi bỏ qua kiểm tra tên miền của chứng chỉ TLS (CVE-2026-105483, -106069); lỗi dns.resolve (CVE-2026-105482). Thêm 6 lỗi nhẹ hơn. Cao Dịch vụ chạy Node.js 22.x, 24.x, 26.x (API, SSR, worker, Next.js, Nuxt). Client gọi HTTPS bằng Node có nguy cơ bị nghe lén. Nâng lên 26.12.1 / 24.22.1 / 22.23.4. Bản đã hết hỗ trợ (EOL) luôn bị ảnh hưởng, cần chuyển bản.
Java Oracle CPU 10-20: 55 bản vá cho Java SE, 49 lỗi khai thác từ xa không cần đăng nhập. Không có lỗi nghiêm trọng (điểm cao nhất khoảng 7.5). Cao Oracle JDK/JRE và OpenJDK cùng nhánh, gồm ứng dụng Spring Boot. Nặng hơn với ứng dụng chạy mã không tin cậy. Nâng lên 27.0.1 / 25.0.5 / 21.0.13 / 17.0.21 / 11.0.33 / 8u511. Đợt tiếp theo: 11-17.
.NET (gồm ASP.NET Core) Patch Tuesday 10-13: hơn 30 CVE cho .NET, 13 CVE cho ASP.NET Core. Đáng chú ý: 5 lỗi chạy mã từ xa (CVSS 8.8), CVE-2026-88092 (can thiệp request, 9.4), CVE-2026-70188 (bỏ qua bảo mật, 9.1). Microsoft xếp tất cả mức Important, chưa thấy bị khai thác. Cao Ứng dụng .NET 8/9/10 và .NET Framework (Windows, Linux, container); web/API ASP.NET Core, nhất là sau reverse proxy. Cập nhật runtime/SDK bản tháng 10, build lại image container.
JavaScript (trình duyệt + npm) Trình duyệt: Chrome 155 (10-06) sửa 247 lỗi, 4 lỗi Critical (có lỗi thoát khỏi sandbox), 53 lỗi High; các bản vá 10-13 và 10-15 sửa thêm lỗi Critical và lỗi ở V8. Chưa thấy bị khai thác trong tháng này. npm: chiến dịch gói độc hại giả "Apex Web3" (10-13) phát tán mã đánh cắp dữ liệu, nhắm cả AI coding agent. Cao Người dùng Chrome, Edge, Brave; ứng dụng Electron/WebView; máy dev và pipeline CI cài gói npm. Cập nhật trình duyệt và Electron. Dùng lockfile, npm ci, tắt install script khi không cần, kiểm tra gói mới thêm.

3. Framework

Next.js Bản vá 10-14: (1) chiếm quyền server từ xa khi use cache trả về typed array, không có cách né tạm; (2) chiếm quyền qua Image Optimization với file SVG (CVE-2026-96889); (3) làm sập server qua Server Actions. Nghiêm trọng Ứng dụng Next.js 15.x và 16.x dùng App Router. Lỗi Image Optimization đến từ thư viện sharp, chạy trên Linux glibc. Nâng lên 16.4.1 / 15.5.28. Riêng CVE-2026-96889 có thể tạm dùng sharp ≥ 0.35.5.
Laravel Advisory 10-19: CVE-2026-114509 (CVSS 9.2) giả danh người dùng mà không cần token, chỉ khi dùng MySQL/MariaDB. CVE-2026-114508 (6.5): request đọc có thể kích hoạt xóa dữ liệu bảng liên quan. Cả hai không có cách né tạm. Nghiêm trọng Ứng dụng Laravel dùng guard token API (TokenGuard) trên MySQL/MariaDB; ứng dụng nạp quan hệ trên endpoint chỉ đọc (12.45.0 đến trước 13.27.0). Vẫn cần vá PHP. Nâng lên 13.29.0 / 12.68.0. Luôn tắt APP_DEBUG ở production.
Quasar Không có advisory mới trong tháng, nhưng nhiều CVE được công bố 10-06/07 cho advisory tháng 7: prototype pollution ở extend(), treo server SSR do regex User-Agent, XSS ở meta tag SSR, ghi file ngoài dự án qua icongenie, khóa TLS dev quyền rộng, DOM clobbering ở openURL(). Cao Ứng dụng Quasar dùng SSR/SSG; máy dev dùng icongenie, @quasar/cli, @quasar/app-vite. Nâng Quasar ≥ 2.32.2 và các gói @quasar/* lên bản mới nhất. Tắt trang lỗi SSR dev ở môi trường dùng chung.
Nuxt Không có CVE mới. Có 5 advisory ngày 10-16 (Moderate/Low): bỏ qua middleware và route rules khi đường dẫn mã hóa % hoặc khác chữ hoa/thường, useHeadSafe chưa lọc đầu vào, <NuxtLink> còn chạy URL javascript:. Còn hiệu lực: CVE-2026-71316 (lộ dữ liệu SSR của người khác qua cache _payload.json, 8.7, bản 4.4.0 đến 4.5.1). Trung bình Ứng dụng Nuxt 3/4 dùng route rules hoặc middleware phân quyền, server island, hoặc cache SSR. Nâng lên bản mới nhất của nhánh (từ 4.5.1 / 3.21.10 trở lên). Chưa rõ số hiệu bản vá của advisory 10-16, cần kiểm tra.
Spring Boot Không có advisory mới trong tháng 10. Còn hiệu lực: CVE-2026-40976 (CVSS 9.1) cấu hình bảo mật web mặc định không có tác dụng, mở mọi endpoint (4.0.0 đến 4.0.5). Tháng 9 có hơn 50 CVE từ Tomcat, Netty. Trung bình Spring Boot 4.0.0 đến 4.0.5 không tự cấu hình Spring Security; ứng dụng dùng Tomcat/Netty cũ. Dùng Spring Boot ≥ 4.0.6 / 3.5.14, cập nhật Tomcat/Netty, quét phụ thuộc kỹ.

5. Ghi chú về độ tin cậy

  • Đã đọc trực tiếp nguồn chính thức: Node.js, Next.js, advisory Laravel, advisory Nuxt, spring.io/security, GCP bulletins, AWS bulletins, danh sách CVE Microsoft qua SANS ISC.
  • Chỉ qua bài tổng hợp: Oracle CPU (trang trả về 403, chưa có danh sách CVE của Java SE); Nuxt tháng 7 và CVE-2026-71316; CVE-2026-48019 (Laravel) và CVE-2026-40976 (Spring Boot).
  • Quasar: điểm số và số hiệu bản vá lấy từ trang tổng hợp, các nguồn mâu thuẫn nhau (ví dụ CVE-2026-106102). Cần đối chiếu trước khi dùng làm căn cứ.
  • JavaScript: số lỗi Chrome ngày 10-13 và 10-15 chưa đối chiếu với Chrome Releases blog; chiến dịch "Apex" chỉ có một nguồn thứ cấp.
  • Nuxt: chưa mở từng advisory ngày 10-16 nên chưa biết số hiệu bản vá chính xác. Laravel: CVE-2026-102279 (XSS trang debug) vá ở 13.30.0 / 12.69.0, xem báo cáo tháng 9.
  • AWS: bản tin không hiển thị mức độ, nên cột mức độ là đánh giá tạm. .NET: mức độ theo CVSS và loại lỗi (Microsoft xếp tất cả Important).
  • Spring Boot: "không có advisory tháng 10" dựa trên một trang spring.io chỉ hiện mục mới nhất; chưa kiểm tra GitHub advisory từng dự án.
